# TECHTODAY – Technology & Digital Media

## Tentang Project

TECHTODAY adalah website portal berita yang menyajikan informasi seputar teknologi dan dunia digital. Website ini dikembangkan menggunakan PHP dengan memanfaatkan NewsAPI dan cURL untuk mengambil serta menampilkan berita dari sumber eksternal.

Project ini dibuat sebagai tugas mata kuliah Pengujian Perangkat Lunak sekaligus sebagai portfolio pengembangan website.

## Fitur Website

- Menampilkan berita teknologi terbaru.
- Menampilkan artikel utama (Featured Story).
- Kategori berita:
  - Artificial Intelligence
  - Gadgets
  - Cybersecurity
  - Software
  - Startups
- Pencarian berita.
- Menampilkan gambar artikel.
- Placeholder otomatis ketika gambar artikel gagal dimuat.
- Tampilan website responsif dan mudah digunakan.

## Cara Menjalankan Website

1. Instal XAMPP pada komputer.
2. Simpan folder project di dalam direktori `htdocs`.
3. Jalankan Apache melalui XAMPP Control Panel.
4. Siapkan API Key dari NewsAPI.
5. Masukkan API Key secara lokal pada konfigurasi project.
6. Buka browser dan akses:

   `http://localhost/the-genz-daily/`

## Sumber Data

Berita diperoleh melalui NewsAPI:
https://newsapi.org/

## Catatan

API Key tidak disertakan dalam repository publik. Pengguna perlu menggunakan API Key masing-masing untuk menjalankan integrasi berita.
